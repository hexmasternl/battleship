# Getting help

- **Getting it running.** Start with the [Quick start](README.md#-quick-start) and
  [Troubleshooting](README.md#troubleshooting) in the README. Most problems are a stopped Docker
  or a missing `dapr init`.
- **Questions about the code or the Aspire setup.** Open an
  [issue](https://github.com/hexmasternl/battleship/issues/new/choose) and describe what you
  tried. Include the output of `aspire --version`, `dotnet --version` and `dapr --version`.
- **Bugs and feature requests.** Use the issue templates. See [`CONTRIBUTING.md`](CONTRIBUTING.md).
- **Security problems.** Never in public. See [`SECURITY.md`](SECURITY.md).
- **Aspire itself.** See the [Aspire documentation](https://aspire.dev) and the
  [Aspire repository](https://github.com/dotnet/aspire).

This project is maintained in spare time, so answers can take a few days.
